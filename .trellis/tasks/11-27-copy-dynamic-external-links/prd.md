# 复制动态中的第三方完整链接

## 目标与来源

按 [README](../../../readme.md) 的描述，提取 UP 主动态推广中的第三方完整目标链接；用户点击链接时直接将其复制到剪贴板，以便用户自行使用。淘宝、京东商品页面是示例。

## 已知事实

- README 描述了期望的点击和复制行为，但没有提供目标宿主中动态数据、跳转链或失败样例。
- 现有 `ShareHook.kt` 和 `FreeCopyHook.kt` 都涉及剪贴板处理；新行为需要检查是否与这些既有功能互相干扰，不能假设当前实现已经覆盖第三方动态链接。

## 需求

- 在确认的动态推广链接场景中获取完整的第三方目标链接，并在用户点击时直接复制，而非要求用户在站内登录后跳转。
- 保留目标链接中打开页面所需的信息，不影响非目标链接的既有点击与复制行为。

## 验收条件（初稿）

- [ ] 在国际版 3.20.4 中使用已确认的第三方动态链接样例，点击后剪贴板获得可用的完整目标链接，包括打开目标页面所需的参数。
- [ ] 覆盖已确认的代表性淘宝、京东等样例，以及无法提取目标链接的情况；记录实际限制和失败行为。
- [ ] 检查与净化分享、长按复制等既有功能同时启用时的行为，非目标链接不发生非预期变化。

## 范围外

- 绕过第三方电商站点自身的登录、购买或访问限制；本需求只处理动态链接的提取与复制。

## 待确定
