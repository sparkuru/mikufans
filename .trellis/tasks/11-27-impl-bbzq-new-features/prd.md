# BBZQ 新功能与修复

## 目标

将 [readme.md 的未完成事项](../../../readme.md)整理为可独立规划、实施和验收的工作，继续维护 Mikufans 对 Bilibili 国际版 `com.bilibili.app.in` 3.20.4 的支持。

## 已知背景

- 项目基于 BBZQ v1.0.3（`15ed308`），原版功能与目标见 [v1.0.3-readme.md](../../../v1.0.3-readme.md)。
- README 包含两项修复和三项新增需求；其详细验收范围、实施顺序和技术方案尚未确定。
- `archive/apks/bilibili-international-3.20.4/` 包含目标版本的 base APK 和拆分 APK；存在文件不代表目标设备或功能已验证。
- 现有项目规范、偏好设置与宿主兼容性、第三方声明及真实用户数据必须得到保留。各子任务应先检查已有实现和目标 APK，并在适用时参考 README 列出的上游和第三方项目。
