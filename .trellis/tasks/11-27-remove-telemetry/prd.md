# 去除遥测

## 目标与来源

处理 [README](../../../readme.md) 隐私分类下的“去遥测”需求，减少目标宿主中经确认属于遥测的数据收集或上报。

## 已知事实

- README 未列出遥测事件、上报目标、SDK 或识别标准；仓库中的名称或字段不能单独证明其为需要阻断的遥测。
- 应通过目标 APK、宿主运行行为以及适用的上游或第三方参考识别证据，并区分功能所需请求与遥测；不得在测试证据中记录账号凭据或私人数据。

## 需求

- 明确目标版本中要处理的遥测范围和证据，对确认的遥测行为实施适配。
- 避免在没有证据的情况下阻断登录、内容加载及其他正常业务通信；记录不能确认或无法覆盖的路径。

## 验收条件（初稿）

- [ ] 列出纳入范围的遥测类型、识别依据和验证方法，并比较修改前后的实际行为或可控样例。
- [ ] 验证已确认遥测在适用场景下按确定规则被处理，同时验证目标宿主的基础登录、内容加载等受影响功能。
- [ ] 记录未覆盖的上报路径、测试限制及证据的脱敏方式，不宣称未经核实的“完全无遥测”。

## 范围外

- 没有证据或需求确认时，对所有网络请求进行无差别拦截，或修改第三方服务端的数据处理行为。
