# 支持账号已购表情包

## 目标与来源

适配 [README](../../../readme.md) 中“账号内合法付费表情包适配支持”的需求，使用户能够在国际版 3.20.4 中使用账号合法拥有的付费表情包。

## 已知事实

- README 未说明受影响的界面、具体失败表现或服务端接口；不能假定已购表情包的加载、展示与发送问题相同。
- 实施前需要检查目标 APK、宿主实况及可用的上游或第三方参考；验证可能依赖具有合法已购表情包的测试账号或其他适当的测试样例。

## 需求

- 在确认的宿主场景中适配当前账号已合法获得的付费表情包，维持账号和服务端原有的权益边界。
- 保持其他表情、账号操作及现有设置正常；测试与记录不得泄露账号凭据、令牌或私人数据。

## 验收条件（初稿）

- [ ] 使用具有合法已购表情包的测试条件，验证确认范围内的展示与使用行为，并记录结果与覆盖场景。
